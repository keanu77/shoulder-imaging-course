# 網頁版型設計建議

## 定位：臨床工作站，不是一般影音 LMS

醫師在使用時最常做的是快速定位結構、核對標準切面、確認陷阱，再決定是否播放示範。因此首頁應先建立課程可信度，進入章節後則提高資訊密度，不以大型人物照片或娛樂型動畫佔據主要空間。

## 建議資訊架構

- 頂列：品牌、課程內容、影片學習、課程標準、搜尋、明暗模式
- 首頁 Hero：診斷限定、醫師對象、24 單元、來源標準及內容審閱狀態
- 桌面課程頁：左側固定章節/進度，右側單元內容
- 單元卡：學習目標 → 必備視圖 → 操作重點 → 常見陷阱 → 自我檢核 → 參考來源
- 影片頁：桌面約 65/35 的播放器與清單；手機改為單欄

## 視覺語言

- 主色：深海軍藍，建立影像工作站與專業醫療感
- 功能色：超音波青綠用於標準視圖與正常流程
- 警示色：紅色只用於誤判、紅旗與安全問題
- 審閱色：琥珀表示待審、青色表示 medical review、綠色表示 approved
- 影像：優先使用去識別化的超音波畫面、探頭方向圖及簡潔線稿；避免裝飾性 stock photo

目前實作採沉浸式臨床工作站外殼：深海軍藍 command bar 與章節軌道、青綠發光狀態、CSS 產生的非病人超音波扇形示意、掃描線及波形。動效只用於狀態與空間層級，並完整遵守 `prefers-reduced-motion`；裝飾畫面不得被描述為真實病例或診斷影像。

## 版型細節

- 單元標題旁固定顯示程度與 `draft / medical-review / approved`
- 單元展開後固定以三欄呈現「必備視圖／產出 → 操作與判讀重點 → 常見陷阱」；青綠、冷藍與淡紅形成穩定掃讀節奏
- 影片卡顯示頻道/機構、發布年、來源權威類型、最後確認日與經典例外理由
- 參考來源放在單元內可見區，不藏在頁尾
- 觸控目標至少 44 px；行寬控制在約 70–80 個中文字元內
- 桌面左側章節軌道維持 sticky；平板與手機轉為可橫向滑動的章節軌道，避免固定側欄壓縮掃描內容
- 390 px 與 320 px 視窗不得產生頁面水平溢位；三個臨床分區在窄螢幕維持原順序改為單欄

## 後續可增加

- 互動式「標準 12 視圖」掃描地圖
- 左右肩與 probe marker 的方向切換
- 正常/異常影像並排比較
- 完成條件以「影像產出」為主，不以看完影片百分比冒充臨床能力
