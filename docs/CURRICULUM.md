# 課程結構

課程採「先建立影像，再辨識結構，最後判讀病理」的順序。第一階段只涵蓋診斷掃描。

| 章節 | 主題 | 單元數 | 核心產出 |
|---|---|---:|---|
| CH0 | 課程定位、能力邊界與安全 | 3 | 知道課程不等於 credentialing，能辨識升級評估時機 |
| CH1 | 影像最佳化與基本技術 | 3 | 可重複的 probe handling 與 artifact control |
| CH2 | 標準肩部掃描流程 | 3 | 依固定順序取得標準切面 |
| CH3 | 前側肩部 | 3 | 肱二頭肌、肩胛下肌與相關動態 |
| CH4 | 上外側肩部 | 3 | 旋轉間隙、棘上肌與肩峰下結構 |
| CH5 | 後側肩部與動態檢查 | 3 | 棘下肌、後盂唇區域及動態觀察 |
| CH6 | 常見病理判讀 | 3 | 以多平面與動態所見整合病理 |
| CH7 | 報告、品質與病例整合 | 3 | 可追溯的圖像、報告與病例推理 |

## 單元完成定義

每個單元至少包含：

- 兩個明確學習目標
- 必備視圖或可觀察的影像成果
- 兩個操作/判讀重點與兩個常見陷阱
- 一項可由學員產出影像、說明或報告的評量
- 一個以上可追溯參考來源
- `draft`、`medical-review` 或 `approved` 狀態

影片是輔助材料，不是課程的唯一內容。若公開影片與課程標準不一致，以經醫療審閱的單元文字與指定指引為準。
