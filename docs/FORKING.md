# Fork 與改作

本 repo 目前為 PUBLIC。這份說明供獲授權的協作者或公開 repo 的使用者參考，不改變存取權限與授權。

1. 先讀 LICENSE、LICENSE-CONTENT.md、NOTICE.md。保留原作者及第三方的著作權與授權聲明。
2. 更換站名、網站網址、頁面作者、社群帳號及品牌素材；清楚標明這是改作，不是吳易澄醫師的官方網站。
3. 先調整 course/course.config.json；再依自己的主題提供 course/data，不直接把原站批准套到新的內容。
4. src/build/contribution_links.py 及 src/build/build.py 目前使用官方課程網址；src/web/index.html 與檢核表／進階頁產生器也有主頁返回網址。 投稿目的地與課程 context 必須改成自己的服務；在未設定前移除入口，不要把改作站的回饋送到原站或冒用原課程網址。
5. 新建自己的 Cloudflare Pages 專案；不要沿用原帳戶、D1、秘密或自訂網域設定。先在本機和自己的 preview 驗證。
6. 更動過的教材以 draft 開始，重新建立審閱紀錄。原版審閱歷史可作出處，但不得宣稱適用於改作版本。
7. 確認畫面、鍵盤、手機、深淺模式及來源連結，再決定是否部署。真實投稿／寄信測試需使用自己的收件管道。

本次提供的是改作說明；尚未把七站合併為單一共用框架，也沒有自動將原始課程變成新的已核准教材。
